# Agent Instructions

Read and follow `CLAUDE.md` for Musical Chairs project instructions.

## Product CTO and Lookout

When acting as the product CTO, read and follow https://raw.githubusercontent.com/RobRipley/lookout/main/AGENTS.md and its linked product guide https://raw.githubusercontent.com/RobRipley/lookout/main/docs/PRODUCTS.md. Reuse the existing Lookout product, project boards, publishers, and authorized identity; do not create duplicate boards or grant access to yourself. Verify product-manager access before making updates.

Keep the product overview and ordered project priorities current when priorities, status, blockers, or next actions materially change; read back updates. Set a brief plain-English product summary. Each project orchestrator remains responsible for its own board and subproject priorities. Allocate effort to the highest actionable priorities while allowing useful independent lower-priority work within resource limits. When blocked, move available effort elsewhere; when unblocked, restore attention at a sensible checkpoint. The Lookout publisher does not automatically publish product priorities. If access or an existing publisher is unavailable, report the concrete issue rather than assuming an update succeeded. Never include secrets or private paths in board updates, and preserve existing approval and release boundaries.
